Welcome to Memory Map

A browser for everything in your Claude Code setup.

What it does

Memory Map indexes every skill, agent, slash command, memory file, plan, hook, and routine Claude has access to — across your global ~/.claude/ setup, your workspace repos, and installed plugins. Pick a tab, click a name, see the file rendered on the right.

Useful for: figuring out what skills are available, what your plugins ship, where your memories live, and what conventions you've set up over time.

Choose your workspace folder

The folder where you keep most of your code repos. Memory Map will look for any <repo>/.claude/ folders inside it and surface their skills, agents, and commands under the Workspace tab.

__WORKSPACE_DISPLAY__

Keep it fresh automatically — optional

Add these to ~/.claude/settings.json under the top-level "hooks" key. They tell Claude Code to rebuild Memory Map's index whenever you start a session, edit a plan, or exit plan mode — so the tree always reflects your current setup.

__HOOKS_JSON__

Without these hooks you can still rebuild manually from the ⚙ Settings menu. Memory Map also auto-rebuilds on every version update.
